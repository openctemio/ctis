# Importer mapping specs

Generated by `go test ./importer -run TestMappingDocs -update`; do not edit.

Each importer converts one exported format to CTIS. Its spec lists every source field it knows and the CTIS member that keeps it, or why it is ignored on purpose. The tests fail when a fixture holds a field its spec does not list, or when a spec maps a field no fixture holds.

- **Spec coverage**: mapped fields as a share of all fields the spec lists.
- **Fixture coverage**: distinct source field paths of the fixtures whose spec row maps them, as a share of all distinct paths the fixtures hold.
